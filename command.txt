# kousoku5.ino シリアルコマンドフォーマット仕様

## 概要
Arduino Uno用のステッピングモータ制御プログラム（kousoku5.ino）で使用される
シリアル通信コマンドの仕様書です。

## 基本フォーマット
```
[STX][PUMP][ACTION][VALUE][CHECKSUM][ETX]
```

## 詳細仕様

| 位置 | サイズ | 内容 | 値 |
|------|--------|------|-----|
| 0 | 1バイト | スタートバイト | `0x02` (STX) |
| 1 | 1バイト | ポンプ番号 | `'1'`, `'2'`, `'3'` |
| 2 | 1バイト | アクション | 各種コマンド（後述） |
| 3-8 | 6バイト | 値（6桁の数字文字列） | `"000000"` 〜 `"999999"` |
| 9 | 1バイト | チェックサム | XOR計算値 |
| 10 | 1バイト | 終了バイト | `0x03` (ETX) |

## チェックサム計算
```cpp
checksum = cmd[1] ^ cmd[2] ^ cmd[3] ^ cmd[4] ^ cmd[5] ^ cmd[6] ^ cmd[7] ^ cmd[8]
```

## サポートされているアクション

| アクション | 説明 | 値の意味 | 例 |
|------------|------|----------|-----|
| `'M'` | モータ開始 | ステップ数（0=無限動作） | `"000100"` = 100ステップ |
| `'S'` | 停止 | 未使用（000000） | `"000000"` |
| `'F'` | 正転 | 未使用（000000） | `"000000"` |
| `'R'` | 逆転 | 未使用（000000） | `"000000"` |
| `'V'` | 速度変更 | RPM値 | `"000300"` = 300 RPM |
| `'E'` | Enable ON | 未使用（000000） | `"000000"` |
| `'D'` | Enable OFF | 未使用（000000） | `"000000"` |
| `'A'` | 台形加速ON/OFF | 0=OFF, 1=ON | `"000001"` = ON |
| `'B'` | バルブ常時Open | 0=OFF, 1=ON | `"000001"` = ON |
| `'L'` | 励磁常時ON | 0=OFF, 1=ON | `"000001"` = ON |
| `'C'` | 電流データ取得 | 未使用（000000） | `"000000"` |
| `'X'` | 回転情報取得 | 未使用（000000） | `"000000"` |
| `'T'` | トータル回転数取得 | 未使用（000000） | `"000000"` |
| `'J'` | 制御状態取得（全ポンプ） | 未使用（000000） | `"000000"` |
| `'Z'` | 緊急停止（全ポンプ） | 未使用（000000） | `"000000"` |

## コマンド例

### 1. ポンプ1を100ステップ動作（台形加速ON）
```
0x02 '1' 'M' "000100" [checksum] 0x03
```

### 2. ポンプ2を停止
```
0x02 '2' 'S' "000000" [checksum] 0x03
```

### 3. ポンプ3を逆転に設定
```
0x02 '3' 'R' "000000" [checksum] 0x03
```

### 4. ポンプ1の速度を300RPMに変更
```
0x02 '1' 'V' "000300" [checksum] 0x03
```

### 5. ポンプ2の台形加速をON
```
0x02 '2' 'A' "000001" [checksum] 0x03
```

### 6. ポンプ1の電流データを取得
```
0x02 '1' 'C' "000000" [checksum] 0x03
```

### 7. ポンプ2のバルブ常時OpenをON
```
0x02 '2' 'B' "000001" [checksum] 0x03
```

### 8. ポンプ3の励磁常時ONをON
```
0x02 '3' 'L' "000001" [checksum] 0x03
```

### 9. ポンプ1の回転情報（RPM）を取得
```
0x02 '1' 'X' "000000" [checksum] 0x03
```

### 10. ポンプ2のトータル回転数を取得
```
0x02 '2' 'T' "000000" [checksum] 0x03
```

### 11. 全ポンプの制御状態を取得
```
0x02 '1' 'J' "000000" [checksum] 0x03
```
※注：制御状態取得コマンドはポンプ番号に関係なく全ポンプの状態を返します

### 12. 全ポンプを緊急停止
```
0x02 '1' 'Z' "000000" [checksum] 0x03
```
※注：緊急停止コマンドはポンプ番号に関係なく全ポンプを停止します

## 特徴

1. **固定長フォーマット**: 常に11バイト
2. **エラー検出**: XORチェックサムによる誤り検出
3. **3ポンプ対応**: ポンプ1〜3まで制御可能
4. **台形加速制御**: アクション`'A'`で台形加速のON/OFF制御
5. **無限動作**: ステップ数0で無限動作モード
6. **即座反映**: 速度変更は即座に反映される
7. **電流検知機能**: 2ms毎にサンプリング、50回分のデータを格納、0.1秒毎に平均値を計算
8. **バルブ常時Open**: アクション`'B'`でバルブを常時開いた状態に保持
9. **励磁常時ON**: アクション`'L'`でポンプ停止中も励磁を維持
10. **回転情報取得**: アクション`'X'`でポンプの回転速度（RPM）を取得
11. **トータル回転数**: アクション`'T'`で累積回転数を取得
12. **制御状態取得**: アクション`'J'`で全ポンプの各種フラグ状態を取得
13. **緊急停止**: アクション`'Z'`で全ポンプを即座に停止

## 通信設定

- **ボーレート**: 9600 bps
- **データビット**: 8
- **パリティ**: なし
- **ストップビット**: 1

## 注意事項

- コマンドは完全な11バイトを受信してから処理されます
- 不正なチェックサムの場合はコマンドが無視されます
- 存在しないポンプ番号（1-3以外）の場合は無視されます（緊急停止を除く）
- 台形加速モードでは、モータの加速・減速が滑らかになります
- 等速モードでは、即座に指定速度で動作します
- 電流検知は2ms毎にサンプリングされ、50回分のデータを循環バッファに格納します
- 電流平均値は0.1秒毎に計算され、最新の平均値が保存されます
- 電流データ取得コマンド（'C'）は最新の事前計算された平均値を返します
- バルブ常時Open（'B'）がONの場合、ポンプ停止中もバルブが開いたままになります
- 励磁常時ON（'L'）がONの場合、ポンプ停止中も励磁がONのままになります
- 制御状態取得（'J'）はポンプ番号に関係なく、全ポンプの状態を返します
- 緊急停止（'Z'）はポンプ番号に関係なく、すべてのポンプを即座に停止します

## 電流検知機能詳細

### センサ仕様
- **センサ**: ACS712
- **入力ピン**: A0, A1, A2（各ポンプ対応）
- **ADC分解能**: 10bit（0-1023）
- **基準電圧**: 5V
- **オフセット電圧**: 2.5V（電流0A時）
- **感度**: 185mV/A

### サンプリング仕様
- **サンプリング間隔**: 2ms
- **データ格納数**: 50回分
- **バッファ方式**: 循環バッファ
- **データ形式**: int型（電流値[mA]）
- **平均値計算間隔**: 0.1秒（100ms）
- **平均値保存**: 最新の事前計算された平均値を保存

### 電流データ取得コマンド（'C'）
アクション `'C'` を送信すると、以下の形式で電流データが返されます：

```
[STX][PUMP][CURRENT][ETX][CS]
```

#### 応答フォーマット
| 位置 | サイズ | 内容 | 値 |
|------|--------|------|-----|
| 0 | 1バイト | スタートバイト | `0x02` (STX) |
| 1 | 1バイト | ポンプ番号 | `'1'`, `'2'`, `'3'` |
| 2-7 | 6バイト | 電流値（符号+5桁整数） | `"+00125"`, `"-00050"` |
| 8 | 1バイト | チェックサム | XOR計算値 |
| 9 | 1バイト | 終了バイト | `0x03` (ETX) |

#### 応答例
```
0x02 '1' "+00125" 0x03 [checksum]
```

- 電流値は0.1秒毎に計算された最新の平均値（mA単位）
- 正の値は `+` 記号付き5桁
- 負の値は `-` 記号付き6桁

## 回転情報取得機能詳細

### 回転情報取得コマンド（'X'）
アクション `'X'` を送信すると、以下の形式で回転情報（RPM）が返されます：

```
[STX][PUMP][RPM][CS][ETX]
```

#### 応答フォーマット
| 位置 | サイズ | 内容 | 値 |
|------|--------|------|-----|
| 0 | 1バイト | スタートバイト | `0x02` (STX) |
| 1 | 1バイト | ポンプ番号 | `'1'`, `'2'`, `'3'` |
| 2-7 | 6バイト | RPM値（6桁整数） | `"000300"`, `"001200"` |
| 8 | 1バイト | チェックサム | XOR計算値 |
| 9 | 1バイト | 終了バイト | `0x03` (ETX) |

#### 応答例
```
0x02 '1' "000300" [checksum] 0x03
```

- RPM値は6桁固定で左側を0埋め
- 外部割り込みピンで検出した回転数から計算
- タイムアウト（3秒間割り込みなし）の場合は0を返す

## トータル回転数取得機能詳細

### トータル回転数取得コマンド（'T'）
アクション `'T'` を送信すると、以下の形式でトータル回転数が返されます：

```
[STX][PUMP][TOTAL][CS][ETX]
```

#### 応答フォーマット
| 位置 | サイズ | 内容 | 値 |
|------|--------|------|-----|
| 0 | 1バイト | スタートバイト | `0x02` (STX) |
| 1 | 1バイト | ポンプ番号 | `'1'`, `'2'`, `'3'` |
| 2-7 | 6バイト | トータル回転数（6桁整数） | `"012345"`, `"999999"` |
| 8 | 1バイト | チェックサム | XOR計算値 |
| 9 | 1バイト | 終了バイト | `0x03` (ETX) |

#### 応答例
```
0x02 '1' "012345" [checksum] 0x03
```

- トータル回転数は6桁固定で左側を0埋め
- EEPROMに保存された累積回転数を取得
- 999999を超えた場合は0にリセットされます

## 制御状態取得機能詳細

### 制御状態取得コマンド（'J'）
アクション `'J'` を送信すると、以下の形式で全ポンプの制御状態が返されます：

```
[STX][PUMP][VALVE][EXCITATION][TRAPEZOID][000][CS][ETX]
```

#### 応答フォーマット
| 位置 | サイズ | 内容 | 値 |
|------|--------|------|-----|
| 0 | 1バイト | スタートバイト | `0x02` (STX) |
| 1 | 1バイト | ポンプ番号 | `'1'`（無視される） |
| 2 | 1バイト | バルブ常時Open状態 | `'0'`〜`'7'` |
| 3 | 1バイト | 励磁常時ON状態 | `'0'`〜`'7'` |
| 4 | 1バイト | 台形加速状態 | `'0'`〜`'7'` |
| 5-7 | 3バイト | 未使用 | `"000"` |
| 8 | 1バイト | チェックサム | XOR計算値 |
| 9 | 1バイト | 終了バイト | `0x03` (ETX) |

#### ビットフィールド表現
各フラグ状態は1桁の数字（0-7）で表現され、3つのポンプの状態をビットで表します：
- bit 0（LSB）: ポンプ1の状態
- bit 1: ポンプ2の状態
- bit 2: ポンプ3の状態

#### 値の例
| 10進数 | 2進数 | ポンプ3 | ポンプ2 | ポンプ1 | 意味 |
|--------|-------|---------|---------|---------|------|
| 0 | 000 | OFF | OFF | OFF | 全ポンプOFF |
| 1 | 001 | OFF | OFF | ON | ポンプ1のみON |
| 2 | 010 | OFF | ON | OFF | ポンプ2のみON |
| 3 | 011 | OFF | ON | ON | ポンプ1,2がON |
| 4 | 100 | ON | OFF | OFF | ポンプ3のみON |
| 5 | 101 | ON | OFF | ON | ポンプ1,3がON |
| 6 | 110 | ON | ON | OFF | ポンプ2,3がON |
| 7 | 111 | ON | ON | ON | 全ポンプON |

#### 応答例
```
0x02 '1' "3" "5" "2" "000" [checksum] 0x03
```

この例の場合：
- バルブ常時Open: 3（2進数011） → ポンプ1,2がON、ポンプ3がOFF
- 励磁常時ON: 5（2進数101） → ポンプ1,3がON、ポンプ2がOFF
- 台形加速: 2（2進数010） → ポンプ2のみON
